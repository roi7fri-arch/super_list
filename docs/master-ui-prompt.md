# Universal UI Master Prompt

Act as a senior product designer + frontend engineer.  
Build an **original** website with the same polished, technical feel as image.armbian.com/#downloads and openclaw.ai (inspiration only, no copied assets/layout/text).

## Stack (required)
- `React` + `TypeScript` + `Tailwind CSS` + `framer-motion`
- Component-based architecture, reusable `Card` system
- Dark mode default, optional light mode

## Design Direction
- Dark gradient hero, premium contrast, clean typography
- Section-by-section storytelling flow
- Strong visual hierarchy (headline → proof → CTA)
- Include testimonials, stats, feature cards, FAQ, final CTA
- Smooth but subtle motion (no distracting animations)

## Visibility & Discoverability (required)
- SEO: semantic headings, metadata, Open Graph/Twitter tags, sitemap, robots
- Performance: lazy loading, optimized images, minimal bundle, Core Web Vitals targets
- Accessibility: WCAG AA contrast, keyboard navigation, visible focus states, `aria` labels
- Conversion visibility: sticky CTA, clear above-the-fold value prop, trust signals, social proof
- Content clarity: short paragraphs, scannable sections, strong CTA copy

## Output required
1. Design tokens (colors, spacing, typography, radius, shadows)
2. Wireframe section map
3. High-fidelity UI spec
4. Production-ready code
5. Responsive states (mobile/tablet/desktop)
6. Interaction states (default/hover/active/loading/empty/error)
7. SEO/performance/accessibility checklist with implemented items

Constraints: keep it concise, modern, deployable, and original.
